# 🚀 System Architecture

```mermaid
flowchart TB

User

User --> React

React["⚛️ React + Vite"]

React --> API

API["🌐 REST API"]

API --> Backend

Backend["🚀 Express Server"]

Backend --> OCR

Backend --> Mongo

OCR["🤖 OCR + AI"]

Mongo["🍃 MongoDB"]

Mongo --> Notification

Notification["🔔 Notification Engine"]

Notification --> React
```
